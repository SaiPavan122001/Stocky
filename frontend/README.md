# frontend

React + TypeScript + Vite + shadcn/ui web app for Stocky, also packaged as an Android app via Capacitor.

## Local development (web)

```sh
npm install
npm run dev
```

Runs on `http://localhost:5173` and expects `backend-go` reachable at the URL in `.env.development` (`http://localhost:8080/api/v1` by default — see `../.env.example` and `../backend-go/README.md`).

## Android (Capacitor)

The native Android project lives in `android/` (generated by `npx cap add android`, committed like normal source).

**One-time setup** (once you have Android Studio + the Android SDK + a JDK installed): open `android/` in Android Studio and let it sync Gradle.

**Build and run against your local backend:**

```sh
npm run build:android-local   # builds with VITE_API_BASE pointed at 10.0.2.2 (see .env.android-local), then `cap sync android`
```

Then open `android/` in Android Studio and run on an emulator or device.

- **Emulator**: `10.0.2.2` (the default in `.env.android-local`) is the emulator's alias for your machine's `localhost`, so it reaches `backend-go` running natively on your machine automatically.
- **Physical device**: edit `.env.android-local` to use your machine's LAN IP instead (device and machine must be on the same Wi-Fi), then rebuild.
- Cleartext (non-HTTPS) traffic to `10.0.2.2`/`localhost` is explicitly allowed for local dev via `android/app/src/main/res/xml/network_security_config.xml` — this is dropped for a real release build once a real HTTPS backend exists.

**After any frontend change** you want reflected in the Android app: re-run `npm run build:android-local` (or your eventual production build + `npx cap sync android`) before rebuilding in Android Studio.

**App icons/splash**: still Capacitor's generated defaults — swap in real branding later via `@capacitor/assets` once artwork exists (source a 1024×1024 icon and 2732×2732 splash under `resources/`, then `npx capacitor-assets generate --android`).
